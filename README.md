
# KinastMinecraftLauncher (kmcl)

指令线矿工手艺发射器

## requirements

- JDK 25 or newer
- highiq

## build

### jar

```
./gradlew build
```

output: `build/libs/kmcl.jar`

---

### native image

```
./gradlew nativeCompile
```

output: `build/native/nativeCompile/kmcl`

## runnnnnnnnn

```
java -jar build/libs/kmcl.jar
```

```
./build/native/nativeCompile/kmcl
```
