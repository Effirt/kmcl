# Kinast Minecraft Launcher

A command line Minecraft launcher

## requirements
- Java 25 or newer
- highiq

## build

```
./gradlew build
```

output: `build/libs/KinastMinecraftLauncher.jar`

## runnnnnnnnnn

```
java -jar build/libs/KinastMinecraftLauncher.jar -h
```
