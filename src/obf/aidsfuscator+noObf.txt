排除与包含
你可以在排除文件中添加以下格式的排除项和包含项：

{
	"token": {
		"class": [
			"example/Exclusion",
			"!example/Inclusion"
		],
		"field": [
			"example/Exclusion.excludedMethod Ljava/lang/String;",
 		     "!example/Inclusions.includedMethod Ljava/lang/String;"
		],
		"method": [ 
			"example/Exclusion.excludedMethod(IJZBDFSCLjava/lang/String;)V",
			"!example/Inclusion.includedMethod(IJZBDFSCLjava/lang/String;)V"
		],
		"annotation": [
			"example/ExampleAnnotation"
		]
	}
}
用以下任一替换：token

global (全局排除该类进行所有混淆。仅适用于Class)
renameClass (排除了Class的更名。仅适用于Class)
renameField (排除Field被重命名。适用于Class和Field)
renameMethod (排除Method被重命名。适用于Class和Method)
localNames (排除 LVT（局部变量表）的名称被清除。适用于类和方法)
lineNumbers (排除了线路编号表（LNT）被混淆。适用于类和方法)
trim (不包括对特定成员的修剪。适用于Class, Field和Method)
methodSalting (排除某种Method被加盐。适用于Class和Method)
classSalting (排除某个Class被加盐。仅适用于Class)
referenceObfuscate (排除某个方法使其引用混淆。适用于Class和Method)
fixConstants (排除Field的值被移动到静态初始化器。适用于Class和Field)
integerEncrypt (排除Class或Method的整数值加密。适用于Class和Method)
stringEncrypt (排除Class或Method的字符串文字加密。适用于Class和Method)
controlFlowFlatten (排除Method被平坦化为开关的控制流。适用于Class和Method)
controlFlowShuffle (排除Method的控制流洗牌。适用于Class和Method)

参考混淆包含
参考混淆包含文件指定了参考混淆候选文件。它使用与排除文件相同的匹配系统。

Method
任意类中命名的Method，包含任意参数和任意返回类型：test

*.test(*)*

任意在任意类中命名的Method，没有参数且有返回类型：testvoid

*.test()V

任何在Class中命名为的Method，带有第一个参数和返回类型：testpkg.TestClasslongjava.lang.String

pkg/TestClass.test(J*)Ljava/lang/String;

任何在Class中命名为test的Method，结尾为subpkg.TestClass, 最后一个参数boolean和返回类型int

*/subpkg/TestClass.test(*Z)I

在一个名为test的Package下，任何Class中命名的Method，包含任意参数和任意返回类型(简称):pkg

*/pkg/*.test(*

Fields
任意Class中命名的Field字段, Field任意：test

*.test *

任意Class中命名的Field, 类型为: test boolean

*.test Z

Class中任意Field, 类型为：test pkg.TestClass java.lang.String

pkg/TestClass.test Ljava/lang/String;

任意Class中以test结尾的Field，类型为: subpkg.TestClass int

*/subpkg/TestClass.test I

在一个名为test的Package下,任何Class中被命名的Field,且类型任意：pkg

*/pkg/*.test *

请记住，Field时必须用空格将类型和名称分开.
